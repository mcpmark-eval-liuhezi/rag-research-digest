# rag-research-digest

Research-to-code digest on retrieval-augmented generation (RAG) to support the decision on whether to build our next internal search feature on RAG.

The full digest — three key arXiv papers, the flagship open-source RAG repository with its recent development activity, and an adopt / pilot / hold recommendation — is published as a comment on issue #1: [RAG adoption research digest](https://github.com/mcpmark-eval-liuhezi/rag-research-digest/issues/1).
